# 南京出发江西自驾五天四晚完整行程
## 南京 → 庐山秀峰 → 南昌滕王阁 → 上饶望仙谷 → 景德镇 → 南京

> **出行日期**：2026年11月14日（周六）— 11月18日（周三）  
> **出行方式**：自驾  
> **行程天数**：5天4晚  
> **核心诉求**：路线尽量不绕路；重点游览李白《望庐山瀑布》相关的庐山秀峰瀑布、滕王阁、望仙谷、景德镇；望仙谷安排景区内住宿；其他住宿优先全季/亚朵。  
> **路线原则**：南京 → 庐山市 → 南昌 → 望仙谷 → 景德镇 → 南京，整体形成闭环，避免上庐山牯岭镇和景点间反复折返。  
> **资料整理日期**：2026年8月28日。开放时间、门票、演出、索道、停车及酒店权益到11月仍可能调整，所有票务均建议在出发前再次以官方渠道为准。

# 一、行程总览

| 日期 | 行程 | 预计主要车程 | 当日核心 | 住宿 |
|---|---|---:|---|---|
| **11/14 周六 D1** | 南京 → 庐山市 | 约500km，5.5–6h（含休息） | 长途驾驶、休整 | **全季酒店（庐山秀峰景区铜锣湾广场店）** |
| **11/15 周日 D2** | 庐山秀峰 → 南昌 | 秀峰至南昌约120–130km，1.5–2h | **李白瀑布 + 滕王阁夕阳/夜景** | **南昌滕王阁八一馆江景亚朵见野酒店** |
| **11/16 周一 D3** | 南昌 → 望仙谷 | 约195km左右，约3h | **望仙谷下午 + 蓝调 + 夜景** | **望仙谷仙宿（景区内）** |
| **11/17 周二 D4** | 望仙谷 → 景德镇 | 约130km左右，约2–2.5h | **中国陶瓷博物馆 + 陶溪川** | **景德镇陶溪川陶阳新村亚朵见野酒店** |
| **11/18 周三 D5** | 景德镇 → 南京 | 约430–440km，约5–5.5h | **陶阳里/御窑 + 返程** | 返回南京 |

### 全程节奏

这条线路的设计重点不是“每天塞满景点”，而是每天抓一个主重点：

- **D1：把长途车程完成，不硬塞景点。**
- **D2：上午专门看李白笔下的庐山瀑布，傍晚看滕王阁。**
- **D3：把完整下午和夜晚留给望仙谷。**
- **D4：从自然景观切换到景德镇陶瓷文化。**
- **D5：上午补陶阳里，午后返南京。**

预计全程驾驶里程约 **1400–1500km**，以高速为主，望仙谷进出有地方道路和山区道路。

# 二、住宿安排

## 第1晚｜11月14日｜庐山市

### 首选
**全季酒店（庐山秀峰景区铜锣湾广场店）**

### 选择理由
- 住宿仍在庐山市山南方向，不需要绕上牯岭镇。
- 第二天前往秀峰方便。
- 连锁酒店品质稳定，适合第一天长途驾驶后的休息。
- 自驾停车相对友好。
- 第一天住宿本质上以“睡好、第二天出发方便”为主，不建议为了景观升级高价房型。

### 房型建议
- 双人：高级大床/高级双床即可。
- 优先选：**含早餐 + 免费取消 + 免费停车**。
- 不必追求景观房。

---

## 第2晚｜11月15日｜南昌

### 首选
**南昌滕王阁八一馆江景亚朵见野酒店**

### 选择理由
- 接近滕王阁和老城区域。
- 适合下午入住后把车停下，步行或短途打车去滕王阁。
- 看完夜景后不用再长距离驾车。
- 亚朵整体睡眠体验适合第二天继续自驾。

### 房型建议
- 优先：安静、高楼层。
- 如价差合理可选江景房；如果价差明显，则普通房型即可。
- 到店后建议先停车，当晚尽量不再挪车。

---

## 第3晚｜11月16日｜望仙谷

### 首选
**望仙谷仙宿（景区内）**

### 这一晚为什么不坚持全季/亚朵
这一晚住宿本身就是行程体验的一部分。住在景区内的主要价值：

1. 夜景结束后不需要再开山区道路。
2. 可以从下午一直玩到晚上，不需要赶末班接驳。
3. 第二天早晨游客少，可再拍一轮峡谷和悬崖建筑。
4. 部分仙宿套餐可能包含景区门票、早餐、接驳等权益。

### 订房时重点核对
- 是否为**景区内**房型。
- 是否包含 **2张景区门票**。
- 门票是否为 **两日有效**。
- 是否含早餐。
- 是否含停车及行李/入住接驳。
- 入住办理地点在哪里。
- 自驾车辆最终停在哪里。

### 房型建议
没必要强求最贵的悬崖景观房。

优先级：

**景区内 + 含票 + 含早餐 + 接驳清楚 > 房间是否网红**

---

## 第4晚｜11月17日｜景德镇

### 首选
**景德镇陶溪川陶阳新村亚朵见野酒店**

### 选择理由
- 靠近陶溪川，适合晚上逛完步行/短途返回。
- 第二天前往陶阳里也方便。
- 适合自驾停车。
- 第四晚需要恢复体力，为第五天430km以上返程做准备。

# 三、每日详细行程

# D1｜11月14日 南京 → 庐山市

## 今日关键词
**长途驾驶、轻松入住、不要上山**

### 时间表

| 时间 | 安排 |
|---|---|
| **06:15** | 起床、最后检查行李 |
| **06:30** | 南京出发 |
| **约09:00** | 高速服务区休息15–20分钟 |
| **约12:30–13:00** | 抵达庐山市 |
| **13:00–14:00** | 午餐 |
| **14:00以后** | 入住全季、休息 |
| **15:30–17:00** | 可选：庐山市区轻松散步，不安排强体力景点 |
| **18:00** | 晚餐 |
| **21:30前** | 建议休息 |

## 导航建议

第一导航目的地直接设置：

**全季酒店（庐山秀峰景区铜锣湾广场店）**

不要导航去：
- 牯岭镇
- 庐山索道上站
- 三叠泉

因为你的庐山目标已经明确为 **秀峰瀑布**，不需要进入山顶核心景区。

## 午晚餐建议

### 可吃
- 江西家常菜
- 鄱阳湖鱼类（选择正规餐厅、明码标价）
- 石耳类菜品
- 竹笋、农家小炒
- 汤类

### 不建议
第一晚不要为了找“网红餐厅”在庐山市区来回开车。第二天需要早起，吃得舒服、清淡即可。

## 今日注意事项

- 第一日近500km，不建议抵达后再去秀峰。
- 加满油/充好电后再休息，避免第二天一早临时找能源补给。
- 晚上检查第二天秀峰天气和降雨。
- 如果当晚或前一两天有雨，通常对第二天瀑布水量是利好，但山路也会更湿滑。

# D2｜11月15日 秀峰瀑布 → 南昌滕王阁

## 今日关键词
**飞流直下三千尺 + 落霞与孤鹜齐飞**

这是五天中最有“诗意主题”的一天，也是整个行程的核心之一。

## 第一站：庐山秀峰

### 为什么是秀峰，而不是三叠泉

本次所说的“庐山瀑布”特指李白《望庐山瀑布》中：

> 日照香炉生紫烟，遥看瀑布挂前川。  
> 飞流直下三千尺，疑是银河落九天。

对应的游览重点应放在 **庐山南麓秀峰景区的瀑布景观一带**，而不是三叠泉。

### 时间表

| 时间 | 安排 |
|---|---|
| **07:00** | 酒店早餐 |
| **07:30** | 退房，行李全部放车上 |
| **07:40左右** | 前往秀峰 |
| **08:00** | 进入秀峰景区 |
| **08:00–09:00** | 龙潭、山麓步道等 |
| **09:00以后** | 如索道正常，按索道开放情况乘坐 |
| **09:30–11:00** | 重点观赏瀑布、香炉峰方向景观 |
| **11:00–11:30** | 下山、返回停车场 |
| **11:45–12:45** | 午餐 |
| **13:00** | 驾车前往南昌 |

### 当前开放信息参考
- 秀峰景区当前公开信息：约 **08:00–17:30**。
- 秀峰索道当前公开信息：约 **09:00开机，16:00停止售票**。
- 11月15日实际运行时间必须在出发前再次确认。

### 推荐游法

如果天气干燥、步道状况好：

**步行游山麓 → 索道上 → 重点观瀑 → 步行下**

这样既省上坡体力，又可以在下山途中换角度看山谷。

如果前一天下雨、路面湿滑：

**索道往返优先**

不要为了“必须徒步”增加滑倒风险。

### 游览时间
**3–3.5小时**足够。

本次不追求把秀峰所有小景点走完，所有时间围绕“瀑布”和“李白意境”服务。

## 秀峰票务

### 当前可见票务情况
2026年庐山票制存在：
- 庐山“一票通”体系；
- OTA仍可见秀峰单景区成人票。

目前OTA可见秀峰单景区成人票约 **56–62元/人**，但11月15日是否仍可单独购买、与庐山一票通如何执行，建议在 **11月10日前后** 打开官方 **“一机游庐山”** 微信/支付宝小程序最终确认。

### 不要提前买错
因为你只去秀峰，不上牯岭镇、不玩三叠泉，所以不要未经确认直接购买昂贵的整套交通或核心景区组合票。

### 必带
- 身份证原件
- 防滑鞋
- 小瓶水
- 轻量背包

- 约 **120–130km**
- 预计 **1.5–2小时**
- 建议 **13:00左右出发**
- 目标 **15:00前后到酒店**

### 到南昌后的原则
**先去酒店，停车后不再开车去滕王阁。**

## 第二站：滕王阁

### 推荐时间

| 时间 | 安排 |
|---|---|
| **15:00–15:30** | 酒店办理入住 |
| **15:40左右** | 步行/打车去滕王阁 |
| **16:00** | 入园 |
| **16:00–17:15** | 主阁、内部展陈、登高看赣江 |
| **约17:20前后** | 等待日落（实际以当天为准） |
| **17:40–18:20** | 看蓝调、拍外观 |
| **18:20–19:20** | 晚餐 |
| **19:30以后** | 回江边看滕王阁夜景/城市灯光 |
| **20:30左右** | 返回酒店 |

11月中旬天黑比夏季早，所以不能按照暑期行程17:30才进景区。

### 当前开放信息参考
当前公开信息显示滕王阁约：
- **08:00–22:00**
- **21:00停止售票/入园**

### 当前成人门票参考
约 **50元/人**。

夜游、演出、数字体验馆、游船等均可能为另外收费项目。

### 推荐玩法
如果第一次去滕王阁，优先顺序：

1. 主阁内部
2. 登高看赣江
3. 王勃/滕王阁文化展示
4. 日落
5. 外围夜景

不必为了“夜游项目”把全部项目都买齐。

## 南昌晚餐

### 推荐菜品
- 南昌拌粉
- 瓦罐汤
- 藜蒿炒腊肉
- 江西辣椒炒肉
- 白糖糕
- 其他赣菜小炒

### 建议区域
滕王阁、大士院及酒店周边即可。

原则：
**步行吃饭，不再开车。**

# D3｜11月16日 南昌 → 望仙谷

## 今日关键词
**慢下来，从白天看到夜晚**

这一天不安排其他上饶景点。所有时间都留给望仙谷。

## 交通

| 时间 | 安排 |
|---|---|
| **07:30–08:30** | 早餐、整理行李 |
| **09:00** | 南昌出发 |
| **约10:30** | 途中服务区短休 |
| **约12:00–12:30** | 抵达望仙谷 |
| **12:30–13:30** | 午餐/办理入住手续/寄存行李 |
| **14:00** | 正式进入景区 |

### 路程
南昌至望仙谷约 **195km左右**，建议按 **3小时** 预留。

后半段为地方道路/山区道路：
- 不超速
- 不抢弯
- 天黑前尽量不再开山路

这也是为什么这一晚必须住景区内。

## 望仙谷住宿办理

### 导航
优先按照 **仙宿预订成功后发送的官方入住指引** 导航。

不要只凭地图猜测直接把车往景区深处开。

### 到达后处理顺序

1. 找到仙宿/度假区指定接待点
2. 确认停车地点
3. 办理入住或寄存行李
4. 确认房费内门票权益
5. 确认早餐地点和时间
6. 确认第二天是否还可以凭房卡/门票再次进入景区

## 望仙谷游览时间轴

### 14:00–16:00｜白天峡谷

重点：
- 峡谷
- 溪流
- 瀑布
- 传统街巷
- 夯土建筑
- 桥梁与山谷视角

这段时间不要一直停留在商店里。

### 16:00–16:40｜提前寻找观景位

望仙谷最漂亮的不是纯黑后的夜景，而是：

**夕阳前 → 蓝调 → 建筑亮灯**

建议提前向核心悬崖建筑观景区域移动，不要17点以后才开始找位置。

### 约17:10–18:30｜全日最重要时段

11月中旬日落约在17:10前后，具体以当天为准。

此时重点：
- 悬崖建筑
- 山谷层次
- 天空仍有蓝色时的灯光
- 桥梁和街巷亮灯
- 远景与近景各拍一轮

这是整趟旅行最值得留出时间拍照的一段。

### 18:30–20:30｜夜游

可安排：
- 景区内晚餐
- 民俗/互动演出
- 老街
- 夜景拍照
- 文创

表演时间每天可能变化，不要为了赶某一场演出打乱核心观景节奏。

### 20:30–21:00｜返回仙宿

不需要赶着离开景区，也不需要夜间再开车。

## 望仙谷票务

### 当前公开参考
- 开放时间约 **09:30–23:00**
- 约 **20:30停止售票**
- 约 **21:00停止入园**
- 当前成人票约 **140元/人**

### 最重要的购票原则
**先看仙宿套餐是否已经含门票，再决定是否单独买票。**

不要出现：
酒店套餐含2张门票，但又提前在平台另外买2张票。

### 订仙宿时必须截图保存
- 房型名称
- 是否含票
- 门票人数
- 门票有效天数
- 早餐人数
- 停车权益
- 接驳权益
- 取消规则

## 望仙谷饮食

### 午餐
抵达后简单吃，不要点太多，避免影响下午游玩。

### 晚餐
直接在景区内解决。

可尝试：
- 上饶地方小炒
- 铅山烫粉
- 灯盏粿/当地米制小吃
- 弋阳年糕类
- 汤粉、热食

11月晚上较凉，建议晚餐安排热食。

# D4｜11月17日 望仙谷 → 景德镇

## 今日关键词
**清晨仙谷 + 中国陶瓷史 + 陶溪川夜生活**

## 早晨望仙谷

| 时间 | 安排 |
|---|---|
| **07:30** | 起床 |
| **08:00** | 早餐 |
| **08:20–09:00** | 如果住宿权益允许，再在景区内轻松走一轮 |
| **09:00–09:30** | 退房、取车 |
| **09:30** | 出发去景德镇 |

清晨的重点不是再刷一遍所有景点，而是：
- 游客少
- 光线柔
- 街巷安静
- 补拍前晚人多时没有拍到的角度

## 交通：望仙谷 → 景德镇

- 约 **130km左右**
- 预计 **2–2.5小时**
- 地方道路 + 高速组合
- 目标 **12:00左右** 到景德镇

## 到达景德镇后

### 12:00–13:00｜午餐
建议先吃，再去酒店。

### 13:00左右｜酒店

# 七、11月出行装备与天气注意事项

## 1. 服装
11月中旬江西昼夜温差明显，山区体感更低。

建议：
- 长袖打底
- 抓绒/卫衣
- 轻薄羽绒或防风外套
- 长裤
- 防滑运动鞋/徒步鞋

望仙谷看夜景时长时间站在户外，保暖外套很有必要。

## 2. 雨具
建议：
- 每人一把折叠伞
- 或轻薄雨衣

秀峰如果前期有雨，瀑布可能更好看，但石阶也更滑。

## 3. 秀峰最重要的天气变量
**不是“晴不晴”，而是出发前一周有没有有效降雨。**

建议在11月10日左右重点检查：
- 秀峰近7天降雨
- 11月15日天气
- 景区是否发布瀑布/索道提示

如果11月上旬长期无雨，瀑布水量可能明显偏小，要提前降低对“飞流直下”的预期。

## 4. 望仙谷
最希望看到的是：
- 无持续大雨
- 能见度正常
- 傍晚不被厚云完全覆盖

阴天也可以看灯光；持续大雨则会明显影响拍照和步行体验。
